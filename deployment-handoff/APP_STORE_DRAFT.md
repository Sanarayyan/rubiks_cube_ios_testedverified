## Proposed English copy

Name: Rubik's Cube Solver
Name status: Draft from the existing app; owner approval and App Store availability not checked.
Subtitle: Enter colors. Follow each move.
Promotional text: Set your 3x3 cube's colors and follow a solution with interactive 3D guidance.
Suggested category: Utilities — pending owner approval.
Version/build in the project: 1.1.0 (2). Confirm build-number availability in App Store Connect before uploading.
Minimum iOS: 15.0, explicitly approved for this release preparation.
Bundle identifier: com.example.rubiksCubeSolver. Owner-team registration/access still requires verification.

Description:

Get help solving your 3x3 cube with clear, step-by-step guidance.

Enter the colors from your cube using the interactive 3D view, face grid, or unfolded net. Request a solution, then follow each move with animated playback. Pause, move forward or backward, and review the sequence at your own pace.

Features:
- Manual color entry in three views.
- Interactive 3D cube visualization.
- Step-by-step solution guidance and animation controls.
- Help pages and a user guide.

An internet connection is required to calculate solutions.

This draft intentionally does not advertise camera scanning, photo recognition, or history: those routes are disabled in the current frontend.

Suggested keywords: cube,solver,3x3,puzzle,rotation,colors,guide
What's New: Initial iOS release. Draft; check whether the owner already has an iOS version before using this.
